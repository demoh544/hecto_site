# Honor 8X (JSN-L21) Bootloader Unlock Guide

Сайт-руководство по разблокировке загрузчика **Honor 8X (JSN-L21)** с использованием **Android Tool** и **HiSuite Proxy**.

## Структура

```
├── index.html      # Главная страница — пошаговая инструкция
├── about.html      # О проекте
├── contact.html    # Контакты
├── blog.html       # Блог / новости
├── css/style.css   # Стили (адаптивные)
├── js/main.js      # Интерактивность (меню, localStorage)
└── README.md
```

## Технологии

- HTML5 (семантика)
- CSS3 (адаптив, тёмная тема)
- JavaScript (localStorage для чеклиста и формы)
- Git + GitHub Pages

## Как опубликовать на GitHub Pages

1. Создайте репозиторий на GitHub.
2. Загрузите все файлы из этой папки в корень репозитория.
3. Settings → Pages → Source: Deploy from a branch → `main` / `/ (root)`.
4. Сайт будет доступен по адресу `https://<username>.github.io/<repo>/`.

## Важно

Материалы носят **образовательный** характер. Разблокировка загрузчика стирает данные и может привести к потере гарантии или повреждению устройства. Действуйте на свой страх и риск.

## Модель

- **Устройство:** Honor 8X  
- **Код:** JSN-L21 (также JSN-L22, JSN-L23)  
- **SoC:** Kirin 710
