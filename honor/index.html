Разблокировка загрузчика Honor 8X

Подробное руководство по разблокировке bootloader с помощью Android Tool и HiSuite Proxy. Позволяет установить кастомные recovery, root и альтернативные прошивки.

Модель

Honor 8X (JSN-L21 / JSN-L22 / JSN-L23). Процессор Kirin 710. Поддержка EMUI 8–9.1.

🛠️

Инструменты

Android Tool (Android Utility), HiSuite Proxy, HiSuite, ADB/Fastboot, драйверы Huawei.

⚠️

Риски

Сброс данных, возможный brick, потеря гарантии. Действуйте на свой страх и риск.

Важно! Разблокировка загрузчика полностью стирает все данные на устройстве. Сделайте резервную копию. Официальный способ получения кода от Huawei больше недоступен. Методы ниже — неофициальные и могут не работать на всех версиях прошивки.

📋 Пошаговая инструкция

1. Подготовка

  • Сделайте полный бэкап данных через HiSuite или вручную (фото, контакты, приложения).
  • Зарядите телефон минимум до 60–70%.
  • Установите на ПК: HiSuite (для драйверов), ADB & Fastboot Platform-Tools.
  • Скачайте Android Tool / Android Utility и HiSuite Proxy.
  • Включите режим разработчика: Настройки → О телефоне → 7 раз нажмите на «Номер сборки».
  • Включите «Отладка по USB» и «Разблокировка OEM» в параметрах разработчика.

2. HiSuite Proxy — даунгрейд / подготовка прошивки

HiSuite Proxy позволяет подменить ответы серверов Huawei и установить нужную версию прошивки (часто требуется даунгрейд до EMUI 9.1 или ниже для успешной разблокировки).

  • Установите совместимую версию HiSuite (рекомендуется 10.x / 11.x).
  • Запустите HiSuite Proxy от имени администратора и выполните SETUP (патч httpcomponent.dll).
  • В Firmware Finder (TeamMT) найдите подходящую прошивку для JSN-L21 (Base + CUST + Preload при необходимости).
  • Вставьте Package URL, Version ID и имя в HiSuite Proxy.
  • Подключите телефон, в HiSuite нажмите «Обновить». Proxy перехватит запрос и подставит нужную прошивку.
HiSuite Proxy полезен для даунгрейда на версии, где ещё работает fastboot oem unlock или проще использовать Android Tool. На EMUI 10+ команда oem unlock часто отсутствует.

3. Android Tool (Android Utility) — разблокировка

Android Utility / Android Tool поддерживает операции с Kirin 710, включая загрузку factory fastboot и снятие защиты.

  • Установите драйверы Huawei USB (из HiSuite) — устройство должно определяться как HUAWEI USB COM 1.0 в режиме testpoint / VCOM.
  • При необходимости используйте testpoint (короткое замыкание точек на плате) для входа в режим COM-порта.
  • В Android Tool выберите модель / CPU: Kirin 710.
  • Выполните «Load Factory Fastboot» или аналогичную операцию разблокировки.
  • После появления fastboot-устройства выполните в командной строке:
fastboot devices
fastboot oem unlock

Или используйте встроенную функцию Unlock в инструменте. Подтвердите на устройстве (кнопка громкости +).

На многих современных сборках Kirin 710 требуется testpoint + специальный loader. Без вскрытия корпуса классический fastboot oem unlock часто недоступен.

4. Проверка результата

fastboot oem lock-state info
# или
fastboot getvar unlocked

Статус должен показывать unlocked / FB LockState: UNLOCKED.
